# Interface localization

Application translations live in `src/shared/locales/en.ts` and `src/shared/locales/pt-BR.ts`. Edit values to change wording; keep message keys stable. Add new keys to both catalogs. Named placeholders such as `{number}` and `{attribute}` must match in both languages; never concatenate translated sentence fragments. The English catalog defines valid keys and parameter names, with automated key/placeholder parity checks.

React screens use `useLocale()` for translation, canonical enum display labels, localized errors, and preference updates. Store message keys or structured errors in state so visible feedback changes when the interface locale changes. Treat generated story text, names, provider/model identifiers, and legacy free-text gender values as content rather than translation keys. Rule display uses the shared numerical constants; `GAME_RULES_TEXT` remains independent narrator input. Markdown transcript formatting is unchanged.

The persisted schema remains version 1. Missing `interfaceLanguage` and `autoReadStory` fields normalize to `en` and `true`; the existing default story language is preserved. `saveStoryPreferences` accepts validated nonempty partial patches and merges them within the write queue. UI consumers patch only their own fields, so one control cannot overwrite an unrelated setting with a stale snapshot. The auto-reading value is storage groundwork; speech controls and playback remain in the later narration tasks.

Main-process operations return a success/error envelope. Known application errors carry a stable catalog key and safe parameters; provider failures use existing failure codes. Unknown errors display a localized generic message without their raw diagnostics. The sandboxed preload unwraps successful values and uses a data-only error marker in `Error.message` because custom Error properties are not retained across `contextBridge`. The renderer decodes this marker and translates it. Do not add English-message matching or runtime application-module imports to the sandboxed preload.
